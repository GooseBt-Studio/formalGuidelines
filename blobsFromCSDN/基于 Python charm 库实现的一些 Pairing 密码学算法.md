基于 Python charm 库实现了一些 Pairing 密码学算法，放在了 [https://github.com/BatchClayderman/Cryptography-Schemes](https://github.com/BatchClayderman/Cryptography-Schemes) 里面。

在正确部署了 Python charm 库后，所有的 Python 脚本都是独立的，即该存储库中不存在一个脚本调用另一个脚本的代码的情况。所有的方案 Python 脚本编程风格高度统一，并具有变量检验（如不需要可将相关代码片段进行注释）。
