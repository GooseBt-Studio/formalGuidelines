本文将介绍一些数据预处理领域常见的“化”概念，如无特殊说明，文中数据集均为有序的，且其中的每一项均在实数范围内，当前数据集表示经过上一步处理后得到的数据集。

# 归一化（Normalization）

|  方式 | 要求 | 处理后结果 |
| - | - | - |
| min-max 归一化 | 数据集中存在至少两个不相等的实数 | 将数据集映射到某个非零区间 |
| Lp 归一化 | 数据集不全为 $0$ 且 $p$ 为正整数 | 使得数据集 $p$ 次方和为 $1$ |
| 最大值归一化 | 数据集不全为 $0$ 且不含有负数 | 使得数据集最大值变为 $1$ |

## min-max 归一化（Min-Max Normalization）

最常用的归一化是 min-max 归一化，即，将数据集 $x_1, x_2, \cdots, x_n$ 通过有限次有序的加减乘除操作映射至 $[\alpha, \beta]$ 区间，其中，数据集 $x_1, x_2, \cdots, x_n$ 须满足 $||\{x_1, x_2, \cdots, x_n\}|| \neq 1$，且有 $\alpha < \beta$。

最常见的 min-max 归一化是，即，将数据集 $x_1, x_2, \cdots, x_n$ 通过减去数据集的最小值再除以当前数据集的最大值映射至 $[0, 1]$ 区间。

例如：

- $(0, 0.5, 1) \to (0, 0.5, 1)$：最小值和最大值已分别是 $0$ 和 $1$，已经归一化，无需执行归一化。
- $(0, 0.4, 0.5) \to (0, 0.8, 1)$：最小值是 $0$，最大值是 $0.5$，不为 $1$，计算可知最大值乘以 $2$ 即可变成 $1$，于是让所有元素乘以 $2$，得到 $(0, 0.8, 1)$，归一化完成。
- $(0.1, 0.3, 0.6) \to (0, 0.4, 1)$：最小值和最大值均不为 $0$ 和 $1$，先将最小值变为 $0$，即让所有元素减去最小值 $0.1$，得到 $(0, 0.2, 0.5)$；此时最小值已为 $0$，处理最大值，让所有元素除以 $0.5$，得到 $(0, 0.4, 1)$；归一化完成。
- $(-1, 3, 9) \to (0, 0.4, 1)$：最小值和最大值均不为 $0$ 和 $1$，先将最小值变为 $0$，即让所有元素减去最小值 $-1$，得到 $(0, 4, 10)$；此时最小值已为 $0$，处理最大值，让所有元素除以 $10$，得到 $(0, 0.4, 1)$；归一化完成。

通过以上例子可知，最常见的 min-max 归一化的基本步骤为：

1) 让所有元素减去数据集的最小值；
2) 让所有元素除以当前数据集的最大值。

以上最常见的 min-max 归一化过程可被一般化，即，将数据集 $x_1, x_2, \cdots, x_n$ 通过有限次有序的加减乘除操作映射至非零区间 $[\alpha, \beta]$，这就形成了一般的 min-max 归一化过程。

例如：

- 要使 $(-1, 3, 9) \to [4, 5]$，可执行 $(-1, 3, 9) \to (0, 0.4, 1) \to (4, 4.4, 5)$，其中最后一步为将所有元素加 4。
- 但如果要实现 $(-1, 3, 9) \to [4, 6]$，则会复杂一些：区间大小为 $2$，考虑先将 $(-1, 3, 9)$ 映射到 $[0, 2]$ 上，于是通过让所有元素减去最小值 $-1$，得到 $(0, 4, 10)$，再通过让所有元素除以最大值 $10$，得到 $(0, 0.4, 1)$，此时所有元素映射到了区间 $[0, 1]$ 上；通过让所有元素乘以目标区间大小，得到 $(0, 0.8, 2)$，此时所有元素映射到了区间 $[0, 2]$ 上；通过让所有元素加上目标区间的最小值，得到 $(4, 4.8, 6)$。

通过以上例子可知，min-max 归一化的基本步骤为：

1) 通过目标区间上界减去下届计算出目标区间大小；
2) 让所有元素减去数据集的最小值；
3) 让所有元素除以当前数据集的最大值；
4) 让所有元素乘以目标区间大小；
5) 让所有元素加上目标区间的最小值。

## Lp 归一化（Lp normalization）

将**非全零**数据集 $x_1, x_2, \cdots, x_n$ 通过乘以同一个系数使得 $|x_1|^p + |x_2|^p + \cdots + |x_n|^p = 1$ 的过程叫 Lp 归一化，该系数通常为 Lp 范数的倒数，其中，Lp 范数的值为 $(|x_1|^p + |x_2|^p + \cdots + |x_n|^p)^\frac{1}{p}$。

最常见的 Lp 归一化应当为向量归一化（Vector Normalization）。在层次分析法中，将**非全零**数据集 $x_1, x_2, \cdots, x_n$ 通过乘以同一个系数使得 $x_1^2 + x_2^2 + \cdots + x_n^2 = 1$ 的过程叫 **向量归一化** 或 **L2 归一化**，该系数通常为 L2 范数的倒数，其中，L2 范数的值为 $\sqrt{x_1^2 + x_2^2 + \cdots + x_n^2}$。如果将整个数据集 $x_1, x_2, \cdots, x_n$ 视为一个向量 $<x_1, x_2, \cdots, x_n>$，则此操作将使得 $\|<x_1, x_2, \cdots, x_n>\| = 1$，该思想常用于处理特征向量或权重向量。

例如：

- $(3, 4)$：L2 范数为 $\sqrt{3^2 + 4^2} = 5$，让所有元素除以 $5$ 后得到 $(0.6, 0.8)$，检验 $0.6^2 + 0.8^2 = 1$，向量归一化完成。
- $(-1, 2, 1, 1, -3)$：L2 范数为 $\sqrt{(-1)^2 + 2^2 + 1^2 + 1^2 + (-3)^2} = 4$，让所有元素除以 $4$ 后得到 $(-0.25, 0.5, 0.25, 0.25, -0.75)$，检验 $(-0.25)^2 + 0.5^2 + 0.25^2 + 0.25^2 + (-0.75)^2 = 1$，向量归一化完成。
- $(0.24, 0.07)$：L2 范数为 $\sqrt{0.24^2 + 0.07^2} = 0.25$，让所有元素除以 $0.25$ 后得到 $(0.96, 0.28)$，检验 $0.96^2 + 0.28^2 = 1$，向量归一化完成。

通过以上例子可知，向量归一化的基本步骤是：

1) 计算所有元素的平方和；
2) 取平方和的平方根得到 L2 范数；
3) 让所有元素除以该范数。

以上向量归一化过程可被一般化，即，将上述的 $2$ 延拓为正整数 $p$（$p = 0$ 时 $p$ 次方根即 $\cfrac{1}{p}$ 次方在实数范围内没有意义），当 $2 | p$ 或元素为非负数时，绝对值符号可以省略。

例如：

1) 对 $(1, 2, 3, 4)$ 执行 L1 归一化：L1 范数为 $(1 + 2 + 3 + 4)^1 = 10$，让所有元素除以 $10$ 后得到 $(0.1, 0.2, 0.3, 0.4)$，检验 $(0.1^1 + 0.2^1 + 0.3^1 + 0.4^1)^1 = 1$，L1 归一化完成。
2) 对 $(1, -2, 3, 4)$ 执行 L1 归一化：L1 范数为 $(1 + |-2| + 3 + 4)^1 = 10$，让所有元素除以 $10$ 后得到 $(0.1, -0.2, 0.3, 0.4)$，检验 $(0.1^1 + |-0.2|^1 + 0.3^1 + 0.4^1)^1 = 1$，L1 归一化完成。
3) 对 $(3, 4, 5)$ 执行 L3 归一化：L3 范数为 $(|3|^3 + |4|^3 + |5|^3)^{\frac{1}{3}} = (27+64+125)^{\frac{1}{3}} = 216^{\frac{1}{3}} = 6$，让所有元素除以 $6$ 后得到 $\left(\cfrac{3}{6}, \cfrac{4}{6}, \cfrac{5}{6}\right) = \left(\cfrac{1}{2}, \cfrac{2}{3}, \cfrac{5}{6}\right)$，检验 $\left( \left(\cfrac{1}{2}\right)^3 + \left(\cfrac{2}{3}\right)^3 + \left(\cfrac{5}{6}\right)^3 \right)^{\frac{1}{3}} = 1$，L3 归一化完成。
4) 对 $(3, 4, -5)$ 执行 L3 归一化：L3 范数为 $(|3|^3 + |4|^3 + |-5|^3)^{1/3} = (27+64+125)^{\frac{1}{3}} = 216^{\frac{1}{3}} = 6$，让所有元素除以 $6$ 后得到 $\left(\cfrac{3}{6}, \cfrac{4}{6}, -\cfrac{5}{6}\right) = \left(\cfrac{1}{2}, \cfrac{2}{3}, -\cfrac{5}{6}\right)$，检验 $\left( \left(\cfrac{1}{2}\right)^3 + \left(\cfrac{2}{3}\right)^3 + \left|-\cfrac{5}{6}\right|^3 \right)^{\frac{1}{3}} = 1$，L3 归一化完成。

通过以上例子可知，向量归一化的基本步骤是：

1) 计算所有元素的 $p$ 次方和；
2) 取 $p$ 次方和的 $p$ 次方根得到 Lp 范数；
3) 让所有元素除以该范数。

## 最大值归一化（Max Normalization）

最大值归一化是将**非全零的非负**数据集 $x_1, x_2, \cdots, x_n$ 通过除以数据集的最大值，使得数据集中最大的数变为 $1$ 的过程。对于正数数据集，归一化后的数据落在 $(0, 1]$ 区间内；如数据集中含有负数或为全零数据集，可先通过 $\mathrm{e}^x$ 转换。

例如：

- $(0.2, 0.5, 1)$：最大值已是 $1$，无需执行最大值归一化，得到 $(0.2, 0.5, 1)$。
- $(2, 4, 5)$：最大值是 $5$，让所有元素除以 $5$，得到 $(0.4, 0.8, 1)$，最大值归一化完成。
- $(0.5, 1.5, 5, 3)$：最大值是 $5$，让所有元素除以 $5$，得到 $(0.1, 0.3, 1, 0.6)$，最大值归一化完成。
- $(10, 20, 30, 40, 50)$：最大值是 $50$，让所有元素除以 $50$，得到 $(0.2, 0.4, 0.6, 0.8, 1)$，最大值归一化完成。

通过以上例子可知，最大值归一化的基本步骤是：

1) 找出数据集中的最大值；
2) 让所有元素除以该最大值。

# 标准化（Standardization）

将数据集 $x_1, x_2, \cdots, x_n$ 通过减去均值并除以标准差，转换为均值为 $0$、标准差为 $1$ 的分布。公式为 $z_i = \cfrac{x_i - \mu}{\sigma}$，其中 $\mu = \cfrac{1}{n}\sum\limits_{i = 1}^n x_i$ 为均值，$\sigma = \sqrt{\cfrac{1}{n}\sum\limits_{i = 1}^n (x_i - \mu)^2}$ 为标准差。标准化不会将数据限制在特定区间，但能消除量纲影响，使数据服从标准正态分布（若原数据近似正态）。

例如：

- $(1, 2, 3)$：均值 $\mu = 2$，标准差 $\sigma \approx 0.816$，标准化后约为 $(-1.225, 0, 1.225)$。
- $(-1, 0, 1)$：均值 $\mu = 0$，标准差 $\sigma \approx 0.816$，标准化后约为 $(-1.225, 0, 1.225)$。

# 正则化（Regularization）

如果仅讨论数学过程或在数据处理语境下，正则化与 Lp 归一化并无不同。

但在不同语境下，我们应当选择更合适的说法：

- 归一化（Normalization）是数学/信号处理领域的标准术语，指将数据缩放到特定范围（如 $[0,1]$）或使范数为1。
- 正则化（Regularization）是机器学习/优化理论的标准术语，指在目标函数中加入惩罚项以防止过拟合，如 L1 正则化（Lasso）和 L2 正则化（Ridge）；损失函数是目标函数的一部分，在监督学习中，目标函数通常由损失函数和可能的正则化项组成。

例如：

- 将 $(3, 4)$ 映射为 $(0.6, 0.8)$ 的过程称为 L2 归一化。
- 在目标函数中或在损失函数后添加 $\lambda \sum w^2$ 的操作则被称为 L2 正则化。

# 正交化（Orthogonalization）

将一组向量 $\bm{v}_1, \bm{v}_2, \cdots, \bm{v}_n$ 通过线性变换转换为两两正交的向量组，且通常保持某些性质（如单位正交则称为标准正交化）。最经典的方法是 Gram-Schmidt 正交化过程：从第一个向量开始，依次减去它在已正交化向量上的投影，得到正交向量组，再可选地除以模长得到标准正交基。

例如：

- 给定 $\bm{v}_1 = (1, 1, 0)$，$\bm{v}_2 = (1, 0, 1)$，$\bm{v}_3 = (0, 1, 1)$，经过 Gram-Schmidt 正交化可得正交向量组：
  $\bm{u}_1 = (1, 1, 0)$，
  $\bm{u}_2 = (0.5, -0.5, 1)$，
  $\bm{u}_3 = \left(-\cfrac{2}{3}, \cfrac{2}{3}, \cfrac{2}{3}\right)$（未归一化）。

正交化常用于数值线性代数、信号处理等领域，使基向量相互独立且便于计算。
